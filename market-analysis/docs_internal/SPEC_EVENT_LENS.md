# SPEC_EVENT_LENS — 事件历史透镜(event_lens)

> Fable 主脑亲写(2026-07-22)。缘起:用户"世界杯决赛后会大涨"直觉——我真算 9 届后 +20 日
> 56% 上涨/均值 -1.5%(低于 60%/+0.6% 基率),历史不支持"大涨"。用户拍板:把"事件→历史类比"
> **系统化**(全集~12 事件类型),让任何直觉能事前对着全历史看,而不是事后看两天。
> 定位:**描述性事件条件收益·非信号非预测非荐股**。六步:①规格 → ②独立审 → ③建 → ④审 → ⑤修 → ⑥亲验。

## 0. 诚实红线(本功能的命门)
- **描述,不主张**:每事件亮"历史上这事之后市场怎么走"的**原始计数**(N 次里 up 几次)+ 基率对照
  + 均值/中位。**不下"有 edge"结论**;小样本(多数事件 9~40 次)→ 不确定性巨大。
- **多重比较诚实**:~12 事件 × 3 窗 = ~36 组比较。**页面顶部大字**:"这是探索性描述、原始计数,
  **未做多重比较校正**——36 组里几组'看着显著'纯属随机;要看 FDR 校正后的裁决去🔭发现页。"
  可选每事件附块自助 p,但**必须紧挨着标"未校正·探索性"**,绝不呈现为"发现"。
  → 这道声明是防"事件透镜变成 p-hacking 后门"的结构性保证。
- 重叠窗口/自相关、过去≠未来、非投资建议。世界杯那条=教学活例(直觉强、记录是掷硬币)。

## 1. 数据与口径
- 基准序列:SP500(SP500_long.csv,1928+)为主、NASDAQ(NASDAQ_COMP_long.csv)为辅。
- 每事件有一个 **date_generator(px_index) → [事件发生日]**(从价格索引+规则派生,或硬编码日期表)。
- 前向收益:入场=事件日**当日或之后首个交易日的收盘**,持有 5/10/20 交易日,`(px[i+h]/px[i]-1)`。
  复用 `stats_util.forward_returns` / 现成 fwd 机件,别手搓。
- 基率对照:同一 horizon **全样本任意起点**的上涨率与均值(诚实参照系)。
- 可选块自助 p:复用 `walk_forward.block_bootstrap_diff`(sel=事件日掩码 vs 其余),block=horizon
  防重叠自相关;**仅描述,紧挨"未校正"标注**。

## 2. 事件注册表(全集·每个=date_generator + 元数据)
派生类(从日历规则算,零外部数据):
1. **世界杯决赛后**——硬编码 9+ 届决赛日(1990-2026,men's FIFA);触发本功能的样例。
2. **美国大选日后**——首个"11 月第一个周一后的周二"(选举年 1928+);
3. **期权到期(月度)**——每月第三个周五;
4. **三巫日(季度)**——3/6/9/12 月第三个周五;
5. **月末月初(turn of month)**——每月最后交易日入场;
6. **圣诞行情(Santa)**——每年最后 5 个交易日入场;
7. **九月首日**——每年 9 月首个交易日;
8. **Sell in May**——每年 5 月首个交易日;
9. **节前**——美股主要假期(元旦/MLK/总统日/耶稣受难日/阵亡将士/独立日/劳工节/感恩节/圣诞)前一交易日。
硬编码日期表类(无免费日历则先用近年硬编码 + 诚实标"仅覆盖 XXXX 起"):
10. **FOMC 决议日后**——复用 `fomc_study.py` 已硬编码的 FOMC 日期表(单一真相源,import 不复制);
11. **CPI 发布日后**——硬编码近年 BLS 发布日(标覆盖区间;拿不到长史就诚实标 n 小);
12. **财报季始**——每年 1/4/7/10 月第二周首日(近似·标"近似锚")。
每事件元数据:`{key, name_zh, name_en, desc_zh/en, date_generator, note}`。加事件=注册表加一项(可扩展)。

## 3. 输出 `event_lens.json`(web+docs)
- 顶层:`generated`、`base_rates`(各 horizon 全样本 up% + mean)、**`honesty`(§0 未校正声明全文)**、
  `n_events`、`n_comparisons`。
- 每事件:`key/name/desc`、`n_occurrences`、各 horizon `{up, n, up_pct, mean_pct, median_pct,
  vs_base_pp(相对基率的差), boot_p(可选·标 uncorrected)}`、`occurrences`(逐次:date + 各 horizon 收益,
  供展开核对)、`next_date`(下一个未来发生日)、`days_to_next`。
- **NASDAQ 版并列**(用户可能关心科技股)。

## 4. 前端 `events.html`(新页·接首页工具格)
- 顶部诚实横幅(§0 未校正声明)+ "🔭 想看 FDR 校正后的真裁决→发现页"链接。
- **即将到来**区:按 days_to_next 升序列近 90 天内的事件("世界杯决赛已过/大选还有 XX 天"),
  每条附"历史上这事后 20 日:up X/N(YY%) vs 基率 ZZ%"——**让用户事前看到**。
- 事件表:每行 name + 3 窗 up%/基率对照,点开看逐次历史 + NASDAQ 版。
- muted 呈现·不红绿渲染情绪(同 D4 克制);数字全活读 json;as-of 具体日期;zh/en;vp.css;无 CDN。
- 每事件卡都带"小样本·未校正·非信号"角标。

## 5. 挂接
run_all 挂在 seasonality 之后(复用日历口径·描述层)·fail-soft·不入 light。**不进 FDR 池、不进
autodiscovery 分母**(那是校正后裁决的地盘;事件透镜是探索性描述,两者边界清楚,页面互链)。

## 6. 测试(≥8·合成/硬编码不碰网络)
1. date_generator 正确:大选日公式(1932→1932-11-08 等抽验)、第三个周五、turn-of-month;
2. 前向收益计算(合成序列手算对齐);3. 基率参照系;4. next_date 取未来最近;
5. 小样本 n<某阈值时不算 boot_p / 标注 low_n;6. honesty 声明进 json(机器守门·防删);
7. FOMC 日期 import 自 fomc_study(单一真相源·非复制);8. 世界杯样例:9 届、+20 日 up 计数复现我上面手算(56%)。

## 停机点
- 任何人想把某事件"晋升为信号/荐股/进 FDR 池当发现" → 停(那要走 candidate_registry+autodiscovery
  的校正裁决,不能从探索性描述抄近道);
- 想删/弱化"未校正·探索性"声明 → 停(那是防吹票机的命门);
- 财报季/CPI 锚不准 → 诚实标近似或标覆盖区间,不硬凑。
